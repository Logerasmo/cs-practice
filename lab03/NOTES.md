Отличия git diff от git show и git log:
git diff - показывает разницу между двумя состояниями проекта(индексами, коммитами)
git show - показывает подробную информацию об одном коммите
git log - показывает список коммитов в хронологическом порядке и подписывает их

Отличие git restore от git restore --source=...:
git restore возвращает проект в состояние последнего коммита, в то время как с помощью --source=... можно задать номер коммита, какой мы хотим вернуть, а так же конкретно файл
